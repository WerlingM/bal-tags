# Cut

Cutting uses the 5x5 badge template that matches the layout.  Load the template into Lightburn.

* Turn "output" off for the registration marks and the outer boundary line, if any, of the art.  We want to cut only badges and lanyard holes.
* Set the speed/power for all bandges and lanyard hole layers (colors) to the appropriate values for the material.  
* Make sure the lanyard holes layer is above the badge layer so it will be cut first, so the outer badge doesn't move slightly if cut before the lanyard holes
* In the Laser panel click the "Optimizations" button and enable "Don't cut overlapping lines".  


Lay a sheet on the laser bed.  Try to align the sheet square to the sides of the bed.  It doesn't have to be perfect, but the straighter it is the faster the cuts will be.  Place flat magnets on the honeycomb along the edges of the board so we can lay the board in the same location every time.  If not then we will need to run the print and cut registration each time.

Perform the print and cut operation to align to the crosses on the corners of the print.

Cut.

Hopefully we now have 25 double sided badges.
